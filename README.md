# Landing Page - Nintendo
Uma "landing page" ou "página de destino" é uma página web especificamente projetada para converter visitantes em leads ou clientes. Normalmente, é a primeira página que um visitante vê após clicar em um link em um anúncio, e-mail de marketing ou outro canal de marketing. Seu principal objetivo é capturar informações do usuário através de um formulário ou incentivá-lo a realizar uma ação específica, como fazer uma compra ou baixar um recurso. Nesse caso, fiz uma Landing Page sobre uma loja Nintendo, utilizei HTML e CSS, além do conceito de landing page, pude aprender também sobre colocar vídeos em páginas, sobre barras de navegação, pude também melhorar minhas habilidades com CSS, principalmente sobre display flex.
